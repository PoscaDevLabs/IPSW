# IPSW
IPSW for iOS and iPadOS 18 made by a former Apple Inc. Operating System Coder (OSC)


# What is an IPSW?

An IPSW is the Operating System Package (OSP) that contains thee ISO that boots the Operating Syste also including other files like Secure.boot and recovery.apple

# Can I install an IPSW on my Android/Linux/Windows/MacOS Device?

NO an IPSW is only available for iPads and iPhones and to custom-ly install them you must use Open-Core-Patcher-Installer-iOS-iPadOS and any attempts to install it on another device will be logged
